## 为什么不全带上

205 张原图合计约 **29 MB**（平均 141 KB，最大 3.2 MB）。全部打进 APK 会让安装包
无谓地涨几十兆，而气泡一次只显示一张。精选 + 缩放后合计约 **154 KB**。
`tools/verify-pet.mts` 会核对本表行数 == 目录里 `.webp` 数 == TS 侧 `PET_STICKERS` 条数，
防止文档、素材、代码三边悄悄分叉。
